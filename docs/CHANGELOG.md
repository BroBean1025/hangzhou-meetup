# 更新日志

## 2026-11-06 · 桌面版、自动更新与出行时间安排

- **Windows 桌面版**：提供安装包与免安装 EXE，无需安装 Node.js，支持不同窗口尺寸、界面缩放和全屏使用。
- **换乘站分级显示**：缩小时合并站点，放大后按线路轨迹中的站位分开显示；目的地路线和方向箭头同步切换，路线耗时不受地图缩放影响。
- **应用内更新**：每天首次打开自动检查新版，也可手动检查；兼容的界面小修复通过轻量补丁刷新生效，较大改动与外壳升级通过完整程序重启安装。安装版、免安装版均支持热补丁，加载失败自动恢复；升级保留自己的高德 Key、出发点偏好和界面设置。
- **到达时间与出发安排**：设置希望到达的日期和时间，倒推每个人的建议出发时刻，支持跨天行程；主界面显示当前北京时间。
- **途中汇合时间表**：展示各人到站、碰面与继续出发的时刻，支持多个汇合点按先后衔接。
- **自定义缓冲**：调整每人途中缓冲和每处汇合预留时间，设置保存在本机；修改时间安排不增加路线查询。

## 2026-11-05 · 首次发布

- **多起点出行比较**：支持校区或地铁站出发，比较前往共同目的地的路线、耗时、换乘和票价。
- **校门接驳**：可选择具体校门及步行、公交、骑行、打车方式，查看接驳路径和时间拆分。
- **途中会合与枢纽估时**：标出行程共用路段的汇合点，展示到杭州主要交通枢纽的估计时间。
- **示例学校与扩展**：内置三所大学的校区与校门数据，可自行添加学校、校区和校门；界面适配电脑和手机浏览器。
