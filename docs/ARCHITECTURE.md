# 架构、数据与维护

浏览器载入 `core/public/index.html` 与带摘要的资源，同源请求 `/api/origin`、`/api/query`。`core/server.mjs` 提供静态页面并调用 `core/lib/metro-service.mjs`；所有供应商请求在后端发起。服务不读取他人的在线网站，不使用内置 Key。

## 数据责任

| 内容 | 主要来源 | 获取方式 |
| --- | --- | --- |
| 杭州站点、线路、网络图、站间路线/票价 | OpenMetro `cn-hangzhou` 与杭州地铁官方票价查询 | 内置 `rail-snapshot.json`，本地路由与查表 |
| 杭海、绍兴站间票价 | 杭海运营票价图、绍兴轨道交通集团官网 | 内置 `regional-fares.json`，跨区域按边界分段相加 |
| 校门至地铁站步行/公交/骑行/驾车 | 高德 Web 服务 API | 有效缓存优先，未命中时用部署者 Key 请求 |
| 任意点目的地的末段步行 | 高德 Web 服务 API | 按需查询 |
| 杭海/绍兴轨道拓扑和时间 | `core/config/regional-network.json` | 已整理的跨城快照，不在日常轨道查询中反复请求高德 |
| 地图底图、校园区域、轨道曲线和校徽 | `core/data/` | 发布快照；前端构建不发网络请求 |

快照不保证当前运营状态。新增站点/校门/线路时要同时更新源数据、服务配置和前端目录，并重新核验，不可仅改一处站名。

## 缓存

独立版使用有界内存与相同请求合并，重启后内存缓存消失。轨道网络与票价随版本更新；路由使用最小堆和起点缓存，票价按站点索引直接读取。步行通常缓存 7 天，骑行 1 天，公交 15 分钟，驾车 5 分钟；校门综合结果不长于对应接驳缓存。`walking-snapshot.json` 仅在原始过期时间之前使用。

前端快照中的初始估时用于快速显示，不能称为实时查询。用户切换校门/方式或发起路线查询后，仍由服务返回可获得的结果。固定快照的更新时间见数据字段，不能将启动时间或构建时间当作原始数据更新时间。

## 东站与汇合点

火车东站和火车东站（东广场）作为同一目的地入口比较，但跨站区仍是方向明确的步行连接。`cross_station_seconds` 是 `transfer_seconds` 的子项，不能在总时间上重复相加。缺少室内几何时显示缺失，不人工补出轨道。

途中汇合要求不同来路汇入相同线路、相同方向的下一段；已同行的下游站不重复推荐，后来者加入会形成新候选。汇合到站时间沿当前目的地行程累计，包含所选校门接驳与已经发生的换乘。

`station_departures` 记录当前行程在各有向乘车区间起点的累计秒数。杭州段逐站权重来自同版本 OpenMetro 网络，只有与该乘车段总秒数一致时才采用；跨城聚合区间保留已知端点，中间站缺失值为未知，不均分、不替换成另一条最短路线。

## 出发与汇合时间安排

时间计算在 `core/src/trip-time.js` 完成，界面统一使用北京时间（UTC+8），不依赖设备所在时区。以目标到达时刻向前传播约束：先确定最晚的共同路段出发时间，再依次安排上游汇合点和各起点出发时间。共同节点以同站、同线路、同下一站为准，冲突的汇合顺序不生成计划。

每人的途中缓冲只加一次，统一放在首次汇合前；每个参与的汇合点单独加汇合预留，因分支行程产生的额外等待也计入。各段向上取整到分钟，所以计划时长可能略长于卡片里四舍五入的原始耗时。到站钟点包含缓冲预算，不代表实际列车到站；不查询首末班或日期对应的公交班次。修改时间和缓冲仅在浏览器重算，不发高德或 OpenMetro 请求。

## 前端图层

绘图、标注、校徽、固定地图控件、提示框和弹窗统一放入 Leaflet 图层。标注与固定控件使用视口坐标，移动/缩放时补偿 mapPane 位移；弹窗高于标注与操作面板。原生 dialog 和目的地下拉框在地图上方。新增绝对定位文字时不要重新挂在地图外层，否则可能再次盖住弹窗。

重叠行程保留真实轨迹，合并为共同路段；点击命中使用独立 SVG 层，防止站点 Canvas 截获路线点击。聚焦不新增供应商请求。

## 原项目与此发行版

本发行版只保留独立 Web 应用；没有 ChatGPT Sites 配置、Cloudflare 项目绑定或旧 Git 历史，也未附带 Codex Skill 运行环境。它覆盖当前网页功能，运行与二次开发不依赖 Codex。后续修改 `core/src/` / `core/lib/`，重建 `core/public/` 即可。

## 时间和数据怎么看

杭州核心地铁优先使用 [OpenMetro](https://openmetro.dev)，高德补充学校接驳、任意选点末段路径和已有的跨城规划快照。当前底图是 OpenStreetMap 数据由 Leaflet 绘制。站点目录、底图与静态时间不代表当前运营状态，查询服务仍需联网。

时间从选定校门或站点参考位置开始，不含校内步行、进出站、安检及铁路大厅内步行。杭州段不含候车，跨城段保留供应商的固定预留项；打车不含叫车等待，骑行不含取还车，公交按供应商方案总时间计算。路线和校门开放情况可能变化，出行前仍需结合官方公告和现场情况判断。

杭州东站的两个地铁站区合并选择，查询会比较实际上下车位置；需要跨站区时，步行时间计入路线和总耗时。枢纽估时算到地铁站，不包含进入高铁大厅或航站楼的时间。

无法取得时间或路线几何时会标明缺失，不将缺失时间当作零，也不用直线替代未知路径。途中汇合的到站时间是所选校门和接驳方式到该站的最短估计，可能与当前行程前半段的逐段累计时间不同。
